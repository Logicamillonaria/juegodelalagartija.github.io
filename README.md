# Dino Game Moderno

Este es un juego estilo dinosaurio inspirado en el clásico de Chrome, pero con un diseño más moderno y llamativo.

## Características
- Dinosaurio que salta con la barra espaciadora.
- Obstáculos y monedas para recolectar.
- Puntuación y vidas visibles.

## Cómo jugar
1. Abre `index.html` en tu navegador.
2. Presiona **Espacio** para saltar.
3. Evita los obstáculos y recolecta monedas para aumentar tu puntuación.

## Archivos
- `index.html`: Estructura del juego.
- `style.css`: Estilos visuales.
- `script.js`: Lógica del juego.
- `README.md`: Información del proyecto.
