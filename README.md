🦖 Dino Sunset Runner

Un clon mejorado y estilizado del clásico juego del Dino, inspirado en el diseño retro-pixelado del atardecer que viste en la imagen.

Este proyecto incluye:
✔️ Movimiento del dinosaurio
✔️ Gravedad realista
✔️ Obstáculos
✔️ Monedas
✔️ Colisiones
✔️ Sistema de puntaje
✔️ Vidas
✔️ Animaciones básicas
✔️ Diseño 100% con HTML, CSS y JS
✔️ Pixel-art estilizado tipo “sunset desert”
